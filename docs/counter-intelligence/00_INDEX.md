## EXECUTIVE SUMMARY

AI Tinkerers is a global network of 87,991 AI builders across 203 cities, founded by Seattle serial entrepreneur Joe Heitzeberg (ex-Madrona Venture Labs). It operates as a hub-and-spoke community platform where centralized infrastructure collects detailed professional profiles (LinkedIn, GitHub, projects, screening responses) from attendees across all chapters, while sponsors - including OpenAI, Anthropic, Google, Microsoft, and Amazon - receive tiered access to talent, projects, and events.

**Key analytical framework:** These events function as **traceroute packets** sent into the global AI builder network. Each event is a probe; the responses (who attends, what they demo, who connects with whom) map the topology of the AI ecosystem. The higher the event quality, the higher the signal fidelity. The "no-pitch zone" is not a limitation — it's the design constraint that keeps the data clean. Participation IS the signal, and the measurement IS the value delivery.

The Asuncion chapter, led by Fabrizio Pfannl (full-stack dev at Intree), operates in a jurisdiction with weaker data protection, uses private venues disclosed only after vetting, and feeds data back to US-based HQ infrastructure.

## THE TRACEROUTE INSIGHT (TL;DR)

> Each event is an ICMP packet. Attendance is the hop response. Demos reveal what each node is processing. Repeat attendance maps persistent routes. Cross-city correlation completes the trace. **The traceroute doesn't degrade the network — it builds it.**

| Traceroute Layer | Event Equivalent | What It Maps |
|---|---|---|
| Hop identity | Who shows up | Node existence and location |
| Latency | How fast they engage | Community activation speed |
| Payload | What they demo | Node capabilities and focus |
| Routing table | Who talks to whom | Network adjacencies |
| TTL persistence | Who comes back monthly | Stable vs transient nodes |
| AS ownership | Who sponsors | Backbone infrastructure control |
